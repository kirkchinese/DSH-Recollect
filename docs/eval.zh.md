# 记忆行为评测（0.1.0）

用 DSH headless 跑 6 个单轮场景：files 模式，`danger-full-access`，记忆目录为空。统计模型是否把信息写进记忆（主题文件和 `MEMORY.md` 索引）。参照组是一个私下使用、逐字照搬 Claude Code 指导的本地实现，它不随本仓库发布。

| 场景 | 期望 | 参照组 | Recollect（最终版，zh + en） |
| --- | --- | --- | --- |
| 明确"记住：只用 pnpm" | 保存 | 2/2 | 6/6 |
| 隐式反馈"别在结尾总结" | 保存 | 2/3 | 6/6 |
| 用户画像"十年嵌入式 C，第一次碰 React" | 保存 | 0/5 | 8/8 |
| 项目期限"下周五代码冻结" | 保存（换算成绝对日期） | 4/5 | 6/6 |
| "记住某文件里有 formatDate 函数" | 不保存，追问不明显的约定 | 3/5 | 6/6 |
| 无关问题"17×23" | 不保存 | 5/5 | 6/6 |

模型：gpt-5.6-luna、gpt-6-luna（经 dsh-codex-connect）。Recollect 一列只统计加入"主动保存的时机"和强化排除规则之后的最终版提示词。参照组的样本更少，且各模型、各轮次的次数不完全对齐，表中数字是趋势参考，不是严格的统计结论。
